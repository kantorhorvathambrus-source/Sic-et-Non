# Quotation verification worksheet

Generated by `node scripts/verification-sheet.mjs`. Do not hand-edit — change
the content files and regenerate.

Every quotation on this site is published with a `verification` level, shown to
the reader. `corroborated` means the wording was confirmed across several
independent sources but nobody has read it in the original. `primary` means
somebody has.

The build environment can search the web but cannot open pages, so it cannot
raise anything above `corroborated`. That is what this worksheet is for: each
row is a few minutes in a browser, and confirming one is a single-field edit —
set `verification` to `primary` in every locale file for that quotation, then
run `npm run verify:content` to see the count move.

Rows are ordered by how cheap they are to check.
